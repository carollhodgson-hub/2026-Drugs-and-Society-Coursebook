This repository contains the complete static coursebook. The homepage is
`index.html`; supporting chapters and images are stored in `topics`, `assets`,
and `data`.

## Publish with GitHub Pages

1. Open this repository in GitHub Desktop.
2. Copy all files and folders from this package into the repository folder.
3. In GitHub Desktop, enter a summary such as `Publish SOC-245 coursebook`.
4. Select **Commit to main**, then **Push origin**.
5. On GitHub, open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select the `main` branch and the `/ (root)` folder, then select **Save**.

The `.nojekyll` file tells GitHub Pages to publish the coursebook exactly as
provided. Do not upload the ZIP itself to the repository; unzip it first.
